# Photo inbox

Drop the zip of the full-quality photos in this folder, then ask Claude to use them.

- Nothing in here is committed except this README. The originals are too big for the repo.
  When they're used, each photo is resized to a sensible web size and copied into `src/assets/`.
- Straight-from-camera files are best: JPG, PNG or TIFF. HEIC (iPhone) photos may need
  exporting as JPG first.
- It helps to group photos in folders by room (`Thingvellir Suite/`, `Hot Tubs/`, …), but any
  structure works.
