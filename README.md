# Fagriskógur Lodge

Website for [fagriskogur.is](https://fagriskogur.is): a static [Astro](https://astro.build) site that replaces the old WordPress install. It is hosted on GitHub Pages.

```sh
npm install
npm run build && npm run preview
```

Pushing to `main` builds and deploys the site. See [CLAUDE.md](CLAUDE.md) for how the project is laid out and for the DNS cutover steps.
